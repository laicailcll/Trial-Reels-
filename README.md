# Trial Reels Field Kit

Reusable worksheets for creators reviewing an Instagram Trial Reel. These files help separate a publishing choice, an observation, and an interpretation. They contain no account data, measured results, success thresholds, or growth predictions.

## Files

- `review-log.csv`: a blank review log. Keep unavailable metrics blank rather than entering zero.
- `content-fit.csv`: an editorial comparison of audience questions and their limits.
- `publishing-checklist.md`: preparation and review checklist.

## Use

Open the CSV files in Excel, Google Sheets, or a text editor. Duplicate the blank review row for each trial. Record the metric labels exactly as displayed in your app. Do not attribute a change in results to a single creative choice when other conditions changed.

The explanatory guide is available at [Trial Reels Guide](https://trialreelsguide.com/what-are-trial-reels/).

## Evidence and limitations

These are planning aids adapted from the site's original editorial worksheets, not an Instagram ranking model or a controlled experiment. A stranger's response does not establish how existing followers will react. Missing observations leave a question unanswered.

Platform reference: [Instagram's Trial Reels announcement](https://creators.instagram.com/blog/instagram-trial-reels). Platform availability and interface details can change; check your own app. No private user information is included.
